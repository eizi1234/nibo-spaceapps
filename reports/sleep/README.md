# Agent 4 — archived aggregate results

These are the results of the completed private Kaggle run dated 2026-11-15, not results of the cleaned notebook being rerun. The original model was frozen before the chronological test. All reported metrics retain their historical numerical values. The grouped fold `selection` field was normalized to valid JSON; its unimplemented inner secondary metric (`inf` placeholder) is represented as `null`, not changed to a measured error. Outer held-out macro MAE remains unchanged.

Folders: `01_development` contains baseline and feature comparisons, tuning and runtime; `03_chronological_test` contains the protected test aggregate results; `04_grouped_evaluation` contains nested fold results and tuning; `05_sensitivity` contains validation-only scenarios; `06_shap` contains aggregate attribution; `07_research_archive` contains residual, ablation and advanced tuning aggregates; `08_export` contains the synthetic CPU verification. `historical_provenance.json` records hashes, not an executable freeze or approval.

The private original reports ZIP remains the authoritative complete archive. Local paths, actual approvals, full run identity/configuration files, model checkpoints, verbose logs and participant-level records were deliberately excluded or sanitized. Selected aggregate figures are included for documentation. No raw PMData or serialized model is included.

PMData repository/paper licensing discrepancy remains unresolved: keep use noncommercial and confirm rights before redistributing restricted artifacts. The reported model is a terrestrial research prototype, not clinical or astronaut-domain validation.
