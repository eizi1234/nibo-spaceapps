# Elevated self-reported fatigue research model

Positive class is fatigue score 1–2 on exact next calendar day. This is a terrestrial wearable/self-report research proxy, not PVT, diagnosis, biological circadian phase, astronaut clearance or mission risk. Unknown ingestion, unzoned Fitbit timestamps, correlated participant-days and small independent cohort limit validity.

Inference is CPU-compatible. Risk probability is exposed only when recorded validation calibration adequacy supports it; otherwise the output is a risk score. Coverage is not confidence. Uncertainty remains null unless separately validated.
